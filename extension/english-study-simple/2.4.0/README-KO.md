# English Study Simple 2.0.0

Marinara Engine 2.4.0용 간단한 영어 학습 확장입니다. 선택한 영어를 AI로 분석하고 단어와 문장을 저장합니다.

## 지원 기능

- 번역, 문법, 뉘앙스, 유사 표현, CEFR 난이도와 전체 분석
- 단어와 문장 저장, 검색, 필터, 즐겨찾기, 편집과 삭제
- 선택 후 분석 버튼과 다른 확장의 선택 작업 버튼 자동 결합
- 최근 분석 10개 유지
- 단어장, 설정과 사용자 지정 AI 프롬프트 백업 및 복원
- 모바일과 라이트·다크 모드 대응

## 데이터 정책

단어장, 즐겨찾기, 설정과 사용자 지정 AI 프롬프트는 영구 데이터로 백업합니다. `analysisHistory`와 현재 분석은 임시 데이터이므로 백업하지 않으며 최신 10개만 유지합니다. 기존 백업에 임시 분석 기록이 포함되어 있어도 복원하지 않습니다.

서버 데이터를 아직 불러오지 못한 상태에서는 기본값을 저장하지 않습니다. 같은 Marinara 서버에 접속한 PC와 모바일은 서버의 확장 저장소를 공유합니다.

## Simple 범위

SRS 복습, 복습 일정, 통계와 배지는 제공하지 않습니다. English Study 정식 버전으로 역내보내기도 지원하지 않습니다.

## 필요한 권한

현재 페이지의 선택 영역을 읽고 학습 UI를 표시하기 위해 `full_page_access`를 사용합니다. AI 분석은 현재 Marinara 연결과 같은 출처의 `/api/generate/raw`를 사용하며 별도의 외부 주소로 직접 전송하지 않습니다.
