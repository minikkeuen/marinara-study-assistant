# English Study 2.0.0

Marinara Engine 2.4.0용 영어 학습 확장입니다. AI 분석, 단어장, 단계형 학습과 재학습, 복습 통계, 백업과 Simple 데이터 가져오기를 제공합니다.

## AI 분석

- 번역
- 문법
- 뉘앙스
- 유사 표현
- CEFR 난이도
- 전체 분석

사용자가 저장하거나 백업에서 복원한 프롬프트는 자동으로 교체하지 않습니다. 새 설치 또는 비어 있는 항목에만 기본 프롬프트가 적용됩니다.

## 복습 알고리즘

신규 카드는 다음 학습 단계를 거칩니다.

```text
10분 → 1일 → 3일 → review
```

Review 카드의 기본 계산은 다음과 같습니다.

- Again: 10분 후 재학습, 이전 간격 보존, lapse 증가
- Hard: 기존 간격 × 1.2
- Good: 기존 간격 × Ease
- Easy: 기존 간격 × Ease × 1.3
- 최소 Ease: 1.3

Again 카드는 현재 세션에서 추적되며 실제 due 시간이 지난 뒤 다시 나타납니다. 복습 우선순위는 학습·재학습, review, 신규 순서입니다. 버튼 아래 시간과 실제 저장되는 `dueAt`은 같은 계산 결과를 사용합니다.

복습 제외 상태는 기존 `suspended` 데이터와 호환됩니다. 내부 학습 상태를 보존하면서 화면과 큐에서는 별도의 복습 제외 상태로 처리합니다.

## 학습 UI

- 드래그·클릭·더블클릭·모바일 길게 누르기 방식은 그대로 유지하며, 어떤 방식이든 텍스트를 잡으면 분석창 대신 `분석` 버튼을 먼저 표시합니다.
- `마리나라 발췌 카드`를 포함해 선택 영역 근처에 나타나는 호환 작업 버튼을 자동으로 찾아 `외부 작업 | 분석` 형태의 하나의 작업 막대로 결합합니다. 여러 확장의 버튼도 차례로 묶으며, 호환 버튼이 없으면 분석 버튼만 독립적으로 표시합니다.
- 통합 분석 버튼은 최소 44px 높이와 충분한 너비를 유지하며, 스크롤·화면 전환·Esc·화면 크기 변경 시 닫힙니다.
- 복습 진행 수와 신규·학습·복습·재등장 대기 수를 텍스트로 표시합니다.
- 정답은 번역을 먼저 보여 주고, 저장된 문법과 뉘앙스는 접이식 추가 해설로 표시합니다.
- 정답 보기 버튼은 보기와 숨기기를 전환하며, 평가 버튼과 숫자 단축키는 정답 공개 전에도 바로 사용할 수 있습니다.
- 단어장 카드의 정보 버튼은 기존 단어 보기 또는 문장 보기를 열어 저장된 AI 분석을 바로 확인합니다.
- 문장/단어 보기의 첫째 줄에는 원문과 복사·세부 정보·즐겨찾기·최근 기록을, 둘째 줄에는 AI 탭과 편집·다시 생성 아이콘을 배치합니다. 세부 정보 아이콘을 다시 누르면 분석으로 돌아갑니다.
- AI 탭은 남은 폭에서 가로로 스크롤되어 작은 화면에서도 탭 이름과 작업 버튼이 서로 겹치지 않습니다.
- 세부 정보는 단어 보기 또는 문장 보기 패널 안에서 열리며, 카드 유형과 복습 일정·횟수, 일정 초기화와 복습 제외를 제공합니다.
- 편집도 같은 단어 보기 또는 문장 보기 패널 안에서 이루어지며 카드 유형, 영어 원문, 번역, 문법, 뉘앙스, 유사 표현과 난이도를 함께 수정할 수 있습니다.
- 확장 패널을 열면 복습 예정 수와 관계없이 단어장을 먼저 표시합니다.
- 단어장·복습·통계와 설정은 하나의 패널 위치를 공유하며, 화면 경계 보정이 발생해도 같은 위치를 유지합니다.
- 복습 카드의 문장/단어 보기·편집·복습 제외 도구는 카드 하단에 고정됩니다.
- 복습 정답의 번역문은 영어 앞면과 같이 가운데 정렬하고, 추가 해설은 왼쪽 정렬을 유지합니다.
- 복습 평가 저장 중에는 평가 버튼을 잠가 중복 입력을 막으며, 현재 세션에서 마지막 평가를 한 번 취소할 수 있습니다.
- 카드에는 단어/문장 보기, 즐겨찾기, 복사와 더보기만 표시하고 편집·일정 초기화·복습 제외·삭제는 내용 높이의 더보기 메뉴에서 제공합니다.
- 더보기 메뉴는 실제 항목 높이만 사용하고 같은 더보기 버튼을 다시 누르면 닫힙니다.
- 단어장 선택 모드에서는 현재 필터 결과 전체 선택과 일괄 즐겨찾기·복습 제외/포함·일정 초기화·삭제를 지원합니다.
- 단어장 상태는 신규, 학습, 복습, 복습 제외로 간단히 표시하며 정확한 일정은 세부 정보에서 확인합니다.

## 데이터와 호환성

내부 데이터 스키마는 3입니다. 확장 배포 버전은 배포 결정 전까지 2.0.0을 유지합니다.

영구 저장 및 백업 대상:

- 단어장과 즐겨찾기
- 복습 상태, 학습 단계, Ease, 간격과 lapse
- 복습 기록과 통계
- 설정과 사용자 지정 AI 프롬프트

백업하지 않는 임시 데이터:

- `analysisHistory`
- `activeAnalysisId`
- 현재 복습 세션 큐와 due 타이머

기존 스키마 2 백업과 Simple 백업을 가져올 수 있습니다. 복원 파일에 `analysisHistory`가 포함되어 있어도 가져오지 않습니다.

단어장과 복습 데이터는 Marinara 서버의 확장 저장소를 사용하므로 같은 서버에 접속한 PC와 모바일이 공유합니다. 서버 데이터를 불러오지 못한 상태에서는 빈 기본값이나 연결 목록을 저장하지 않으며, 모바일이 다시 활성화되면 서버 데이터를 새로 불러옵니다.

## 필요한 권한

현재 페이지의 선택 영역을 읽고 학습 UI를 표시하기 위해 `full_page_access`를 사용합니다. AI 분석 시 선택한 영어 텍스트와 프롬프트를 현재 Marinara 연결을 통해 같은 출처의 `/api/generate/raw`로 보냅니다. 연결 목록은 `/api/connections`에서 읽습니다. 별도의 외부 주소로 직접 요청하지 않습니다.

## 설치

Marinara 2.4.0의 External Extensions에서 배포 ZIP을 가져오십시오. 새 해시와 `full_page_access` 권한을 검토한 뒤 실행하십시오. 기존 `English Study`와 같은 이름으로 가져오면 저장 데이터는 유지되고 코드는 비활성 업데이트로 교체됩니다.
